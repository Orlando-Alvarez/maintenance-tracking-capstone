# Maintenance Tracking Capstone

Public sanitized project brief for an academic full-stack capstone focused on preventive maintenance and calibration tracking.

This repository contains a short public project brief. Company-specific records, logos, employee names, internal contacts, source-code snippets, private file paths, and original attachments have been removed.

## Project Summary

The capstone team designed a web application to move preventive maintenance and calibration tracking away from a manual Excel/SharePoint workflow and into a centralized system.

## Tech Stack

- React
- Refine
- TypeScript
- ASP.NET Core
- Entity Framework
- SQL database design
