# Maintenance Tracking Capstone

Public sanitized project brief for an academic full-stack capstone focused on preventive maintenance and calibration tracking.

This repository contains a short public project brief. Company-specific records, logos, employee names, internal contacts, source-code snippets, private file paths, and original attachments have been removed.

## Project Summary

The capstone team designed a web application to move preventive maintenance and calibration tracking away from a manual Excel/SharePoint workflow and into a centralized system.

The project focused on improving task visibility, maintenance history, calibration tracking, structured data entry, and KPI-based reporting for a manufacturing environment.

## Problem Addressed

The original workflow relied on a shared spreadsheet process where users had to download, edit, and re-upload maintenance and calibration records. This created risks around delayed updates, version conflicts, duplicate or missing equipment identifiers, limited traceability, and low visibility for supervisors and technicians.

The proposed system was designed to provide a more structured way to track maintenance tasks, calibration status, equipment records, historical activity, and performance metrics.

## Project Scope

The system was designed around approximately 200 production devices requiring preventive maintenance or calibration tracking. Primary users included supervisors, administrators, and technicians.

Core workflows included:

- Viewing equipment records
- Tracking preventive maintenance tasks
- Tracking calibration status
- Updating task completion status
- Recording maintenance history
- Supporting administrator and technician workflows
- Improving visibility through dashboards and reports

## Evaluation Targets

The project defined measurable targets to evaluate whether the system would improve tracking speed, traceability, and user efficiency.

Examples of evaluation targets included:

- 90%+ target on-time task completion
- Registration delay reduced to under 1 day
- 40–60% target reduction in user interaction time
- Near-zero duplicate or invalid entries through validation rules
- Improved visibility into maintenance and calibration history

These metrics are evaluation targets or estimates from project analysis, not production-verified results.
